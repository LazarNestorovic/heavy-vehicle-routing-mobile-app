# Decisions (ADR-stil)

Kratki zapisi tehničkih/arhitektonskih odluka: šta je izabrano, koje su bile alternative, i **zašto**. Ime: `NNNN-kratak-opis.md`, rastući broj (`0001-...`, `0002-...`).

Ovo nije mesto za popravke bagova (to ide u [`../fixes/`](../fixes/)) — ovde ide isključivo "birali smo između X i Y, izabrali smo X jer...". Vredi zapisati čak i odluke koje deluju očigledno danas — za mesec dana pred odbranom neće biti.

## Template

```markdown
# Naslov odluke

**Datum:** YYYY-MM-DD
**Status:** prihvaćeno / zamenjeno od strane NNNN

## Kontekst
...

## Alternative razmatrane
...

## Odluka
...

## Posledice
...
```
