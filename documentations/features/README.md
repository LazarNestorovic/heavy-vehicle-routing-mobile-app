# Features

Jedan fajl po novoj komponenti/mogućnosti dodatoj u sistem (ne popravka postojećeg — to ide u [`../fixes/`](../fixes/)). Ime: `YYYY-MM-DD-kratak-opis.md`.

Svaki zapis treba da pokrije: šta je dodato, gde se nalazi u kodu, kako se testira/pokreće, i šta namerno **nije** urađeno (scope cut zbog roka — vidi `SPECIFIKACIJA.md`).
